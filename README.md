Knowledge Discovery and Data Mining (CIS 635-01)
This repository contains the coursework, projects, and research implementations for CIS 635: Knowledge Discovery and Data Mining. The content is structured into modules covering the end-to-end pipeline of data mining—from preprocessing and feature engineering to advanced machine learning models.

📂 Repository Structure
The curriculum is organized into the following modules:

Module 1: Intro to Data Mining – Fundamentals of KDD and data types.

Module 2: Descriptive Statistics – Data distribution, central tendency, and dispersion.

Module 3: Data Cleaning & Integration – Handling missing values, noise, and data fusion.

Module 4: Spatial Temporal Data – Analysis of data associated with location and time.

Module 5: Similarity and Distance – Proximity measures (Euclidean, Cosine, Manhattan, etc.).

Module 6: Feature Analysis & Relationships – Correlation, covariance, and dependency.

Module 7: Feature Extraction & Selection – Dimensionality reduction and attribute subset selection.

Module 8: Supervised vs. Unsupervised Learning – Comparative analysis of learning paradigms.

Module 9: Classification – Decision trees, Naive Bayes, and performance evaluation.

Module 10: Clustering – K-Means, Hierarchical, and Density-based clustering.

Module 11: Neural Networks & Deep Learning – Advanced pattern recognition and architecture.

🛠️ Technologies Used
Language: Python (or R, depending on your assignments)

Libraries: pandas, numpy, scikit-learn, matplotlib, seaborn

Tools: Jupyter Notebooks
