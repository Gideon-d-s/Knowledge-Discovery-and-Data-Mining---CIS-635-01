# Knowledge Discovery and Data Mining (CIS 635-01)

Welcome to my data mining and knowledge discovery repository! This repository contains my coursework, projects, and notes from a deep dive into data preprocessing, pattern recognition, and predictive modeling.

## 📖 Overview

This repository tracks my progress through various data mining techniques, starting from foundational descriptive statistics and advancing through spatial-temporal analysis, feature engineering, and advanced machine learning architectures.

## 📂 Repository Structure

The curriculum is organized by module, alongside supplementary materials for comprehensive study.

### Coursework by Module

* **[Module 1 - Intro to Data Mining](./Module%201%20Intro%20to%20Data%20Mining)**: Fundamentals of the KDD process and data types.
* **[Module 2 - Descriptive Statistics](./Module%202%20Descriptive%20Statistics%20a...)**: Exploring data distributions, central tendency, and dispersion.

* **[Module 4 - Spatial Temporal Data](./Module%204%20Spatial%20Temporal%20Data%20...)**: Analyzing patterns in data across location and time.
* **[Module 5 - Similarity and Distance](./Module%205%20Similarity%20and%20Distance...)**: Proximity measures and their applications in mining.
* **[Module 6 - Feature Analysis](./Module%206%20Feature%20Analysis%20Relati...)**: Understanding relationships via correlation and covariance.
* **[Module 7 - Feature Extraction](./Module%207%20Feature%20Extraction,%20Sele...)**: Dimensionality reduction and attribute selection.
* **[Module 8 - Supervised vs Unsupervised](./Module%208%20SupervisedUnsupervised...)**: Comparative study of learning paradigms.
* **[Module 9 - Classification](./Module%209%20Classification)**: Decision trees, Naive Bayes, and evaluation metrics.
* **[Module 10 - Clustering](./Module%2010%20Clustering)**: Grouping data using K-Means, Hierarchical, and Density-based methods.
* **[Module 11 - Neural Networks](./Module%2011%20Neural%20Network%20and%20...)**: Introduction to deep learning and complex pattern recognition.
